# Files for Windows NT 4.0. Not enough to warrant its own repo.

7z920.exe is the last 7-Zip to work on NT 4.0

hal.dll/ contains HALs to actually shutdown on shutdown for APM/ACPI PC

immc.exe is Microsoft Management Console 1.2

InstMsiW.exe is Windows Installer (MSIEXEC) 2.0

NT4.0_USB_PATCH allows USB 1.0/1.1 controllers to work

Q299444i.exe is Post Service Pack 6a rollup

unicows.exe is Unicode layer for Windows 98/Me

You can install Internet Explorer 5.5 or 6.0 from [parent dir](../PROGS).

 - For service pack 6a, you can download ISO from WinWorldPC https://winworldpc.com/product/windows-nt-40/patches
